# The notices the shipped libraries need beyond the Apache License's text (#488), read by
# `listLibraryLicences`, which writes the in-app list of libraries (`assets/licences/libraries.txt`)
# from it and from the libraries' own POMs.
#
# A library whose POM names only the Apache License 2.0 takes the license's text
# (`assets/licences/apache-2.0.txt`). A library needs a line here when its POM names another licence
# (MIT and BSD ask that the copyright and permission notice go with every copy), when its jar or AAR
# carries a NOTICE file (Apache-2.0, 4(d)), and when its AAR brings assets into the APK. The build
# finds those. A line may also add what it cannot find, so each is reviewed: the NOTICE file of a
# library's upstream distribution that its jar leaves out, and the licence of third-party code or
# data inside a library, from the library's own licence documents. The build fails on a library
# with no line it needs, on a line that matches nothing, and on a notice that lacks its licence's
# whole text (`build-logic/src/main/resources/sleevesight/licences/`), a copyright line (but for the
# MPL), the library's own copyright lines, or the text of the NOTICE file its jar carries.
#
# An entry matches as in `dependency-allowlist.txt`: its group exactly, `group.*` its subgroups as
# well, and `group:name` that one module; `group:prefix*` also matches each module of the group
# whose name starts with the prefix. The licence is that of what the notice covers. The notice is a
# file in `app/src/main/assets/licences/`; the name, the rest of the line, titles it in the credits.
#
# Checked and needing no line (2026-10-25): Kotlin's `license/NOTICE.txt` is for the compiler's
# distribution; the GWT and Guava code in Kotlin's standard library is Apache-2.0 with no NOTICE
# file, and its Boost code (BSL-1.0) asks nothing of binaries; emoji2's `libs/repackaged.jar` is
# FlatBuffers, Apache-2.0 with no NOTICE file. Ktor, OkHttp, Okio, SQLDelight, Guava, JSpecify,
# Poko and the JetBrains annotations have no NOTICE file at the versions shipped.
#
