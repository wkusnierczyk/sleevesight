API keys to a QR code

Put your API keys in one QR code, and save them all in Sleevesight at once: on the phone, Settings, API keys, Scan keys.

  1. Choose your keys file, drop it here, or paste each key in its field. The file has one NAME=value line a key, such as SLEEVESIGHT_ANTHROPIC_API_KEY=sk-ant-…; lines naming nothing Sleevesight uses are left out. A file replaces what is in the fields.
    or drop it here

  2. Scan the code with Scan keys. The phone lists what it found, each key by its last four characters, before it saves anything.

    No key yet.

  3. Once the phone has saved them, choose Clear, or close this tab.

Nothing leaves your computer. The page is allowed no network request, uses no code from elsewhere and stores nothing: the keys are kept only while the tab is open, and the code is drawn here. Never make such a code with an online QR generator: it would receive your keys. The QR code is the keys: do not leave it on screen, or take a photo or screenshot of it.
