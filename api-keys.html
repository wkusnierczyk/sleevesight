API keys to a QR code

Put your API keys in one QR code, and save them all in Sleevesight at once: on the phone, Settings, Secrets, Load keys. The code is sealed with five words the phone shows: it opens only with them, so a photo or a screenshot of the code alone gives nothing away.

  1. On the phone, open Load keys: it shows five words. Type them here, in their order, with spaces between; the first three letters of each are enough.

    Not sealed: the code is the keys themselves, and anyone who sees it, or a photo of it, has them. Only for a key’s own Scan QR code, which reads no words; Load keys reads a sealed code.

  2. Choose your keys file, drop it here, or paste each key in its field. The file has one NAME=value line a key, such as SLEEVESIGHT_ANTHROPIC_API_KEY=sk-ant-…, named as Sleevesight names it or as its provider usually does: SLEEVESIGHT_ANTHROPIC_API_KEY or ANTHROPIC_API_KEY, SLEEVESIGHT_OPENAI_API_KEY or OPENAI_API_KEY, SLEEVESIGHT_GOOGLE_API_KEY, GEMINI_API_KEY or GOOGLE_API_KEY, SLEEVESIGHT_EXA_API_KEY or EXA_API_KEY, and SLEEVESIGHT_LASTFM_API_KEY or LASTFM_API_KEY. Of the names a file gives one key under, the first listed wins; lines naming nothing Sleevesight uses are left out. A file replaces what is in the fields.
    or drop it here

  3. On the phone, choose Next, and scan the code. The phone opens it with its words, and lists what it found, each key by its last four characters, before it saves anything.

    No key yet.

  4. Once the phone has saved them, choose Clear, or close this tab. Saving a key switches no service on: on the phone, switch on the ones you want under Sources and AI services.

Nothing leaves your computer. The page is allowed no network request, uses no code from elsewhere and stores nothing: the keys and the words are kept only while the tab is open, and the code is drawn here. Never make such a code with an online QR generator: it would receive your keys. The words seal the code in the browser (a key derived from them with PBKDF2, 600,000 rounds, then AES-GCM): it opens only with them. The phone takes it once, within 5 minutes of showing the words, but anyone who has both the code and the words can open it, anywhere, at any time; with the code alone, they must search for the words, some thousands of GPU-years of work. The words are masked here, since a screenshot of both would open the code; if a code and its words get out together, replace the keys at their services. A code made without the words is the keys: do not leave it on screen, or take a photo or screenshot of it.
