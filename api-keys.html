This page makes a QR code for your phone to scan and import your API keys. Open it on a computer or another suitable device that already has those keys available. On the phone you are importing those keys into, scan the QR code with Load keys, or type each key in its own field: Settings, Secrets.

API keys to a QR code

Embed all your API keys in one QR code. Sleevesight scans the code and reads all keys at once. Check Settings, Secrets, Load keys on your phone.

This page runs exclusively in your browser: nothing you type here is sent anywhere. See How your keys stay safe

1Type the words

On the phone, open Settings, Secrets, Load keys. It will show you five words. Type the words in the boxes below, in the same order, one a box. The first three letters of each are enough.

What a keys file looks like

One NAME=value line a key, such as:

SLEEVESIGHT_ANTHROPIC_API_KEY=sk-ant-…
LASTFM_API_KEY=0123…

Sleevesight reads these names. Where a file gives one key under several of them, the first listed wins:

KeyNames, in order

Lines naming nothing Sleevesight uses are left out. A file replaces what is in the fields.

3Scan the code

On the phone, choose Next, and point the camera at the code. The code provides API keys encrypted with the five words from the preceding screen, and only your phone can decode them.

Not sealed: this code is the keys themselves. Anyone who sees it, or a photo of it, has them.

4Finish on the phone

The phone lists the keys it found, each by its last four characters, and asks which to save and which services to switch on.
Once the keys are on your phone, choose Clear, or close this tab.

A code without the words, for a single key

A key’s own Scan QR code, in its key dialog, reads a code made without the words. Such a code is the keys themselves: anyone who sees it, or a photo of it, has them. Load keys reads only a sealed code.

How your keys stay safe

  • Nothing leaves this computer. The page may make no network request, uses no code from elsewhere, and stores nothing. The keys and the words are kept only while this tab is open, and the code is drawn here.
  • Never use an online QR generator for such a code: it would receive your keys.
  • The words seal the code in this browser, with a key derived from them (PBKDF2, 600,000 rounds, then AES-GCM). The code opens only with them.
  • The phone takes the code once, within 5 minutes of showing the words. But anyone who has both the code and the words can open it, anywhere, at any time. With the code alone, they must search for the words: some thousands of GPU-years of work.
  • The words are masked here, since a screenshot of both would open the code. If a code and its words get out together, replace the keys at their services.
  • A code without the words is the keys. Do not leave it on screen, or take a photo or screenshot of it.
